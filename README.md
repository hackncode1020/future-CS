# 🎉 Future-Cs 🎓🎂✨

A premium, cinematic birthday surprise website created to celebrate an inspiring mentor, guide, and future Company Secretary. This project is a heartfelt digital experience filled with warmth, motivation, gratitude, and joyful celebration.

## ✨ What this website includes

- Elegant and immersive birthday landing experience
- Secret unlock gate for a personalized reveal
- Cinematic opening animation and golden particle effects
- Emotional personal letter and appreciation section
- Mentor recognition and motivation storytelling
- CS journey highlight with meaningful encouragement
- Birthday countdown and celebration moments
- Funny surprise moments and heartfelt wishes
- Final festive message with a grand celebration finish

## 🛠️ Tech stack

- React 19
- Vite
- TypeScript
- CSS styling with custom animations
- Interactive visual effects and layered section design

## 🚀 Run locally

### Prerequisites

- Node.js installed

### Steps

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the app in the browser:
   ```bash
   http://localhost:3000
   ```
